# 📐 Pipe Support Drawing Data Extractor

파이프 서포트(Spring Hanger 등) PDF 도면에서 주요 수치를 정밀 파싱하여 엑셀 성능시험지 양식에 자동 기입하는 프로그램입니다.

## 📌 주요 기능
- PDF Vector 도면 내부의 텍스트 레이어를 100% 정확도로 파싱
- SUPPORT TAG NO., SPRING RATE, HOT LOAD, COLD LOAD, HOT POINT, COLD POINT 수치 자동 추출
- 엑셀 시트 내 SUPPORT TAG 매칭 후 해당 행의 지정 셀에 수치 자동 입력
